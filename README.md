# MiGamingMouse2UpdaterV2.0
Файл MiGamingMouse2UpdaterV2.0.zip (обновление прошивки для мыши Xiaomi Mi Gaming Mouse 2)

Важное примечание по установке:
Для корректного обновления прошивки необходимо обновить как саму мышь, так и беспроводной донгл.
Для этого подключите донгл к USB-порту компьютера и одновременно подключите саму мышь к ПК с помощью USB-кабеля.
